Create .docx to .html converter service. This service will convert user inputed .docx file to .html file and store html content into database.

- [ ] Show correct uploading UI with progressbar and text on top that is showing current status

- [ ] Set this newly uploaded document as Active and deactivate last TOS
- [ ] display generated .html content in @tos-disclaimer.tsx inside modal body
- [ ] use best-practises for Next.js project and React.
